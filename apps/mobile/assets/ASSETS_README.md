# Uygulama Asset'leri

## Mevcut Dosyalar

- `images/icon.png` - Ana uygulama ikonu (placeholder)
- `images/splash-icon.png` - Açılış ekranı ikonu
- `images/android-icon-foreground.png` - Android adaptive icon
- `images/android-icon-background.png` - Android adaptive icon arka plan
- `images/android-icon-monochrome.png` - Android monokrom ikon

## Önerilen Boyutlar

- **icon.png:** 1024x1024 px
- **splash-icon.png:** ~200px genişlik (Expo splash resizeMode: contain)
- **Android adaptive:** 1024x1024 px (foreground), 432x432 px (background)

## Özelleştirme

Placeholder ikonları kendi tasarımlarınızla değiştirin. Expo `npx expo prebuild` ile native projeleri oluşturduğunda bu dosyaları kullanır.
