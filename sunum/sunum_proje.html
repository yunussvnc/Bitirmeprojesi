📋 Proje Hakkında

Bu proje, kullanıcıların doğal dilde ifade ettikleri ihtiyaç, duygu ve tercihlere göre konum bazlı kişiselleştirilmiş mekan önerileri sunabilen LLM tabanlı bir sistem geliştirmeyi amaçlamaktadır.

🎯 Ana Hedefler

  • Doğal dil işleme ile kullanıcı niyetini anlama
  • Semantik arama ile en uygun mekanları bulma
  • Konum bazlı filtreleme ve sıralama
  • Kişiselleştirilmiş öneri metinleri üretme
  • Duygusal ve sosyal durum analizi
  • Çoklu özellik eşleştirme (fiziksel + duygusal + sosyal)

🏗️ RAG Mimarisi (Yunusemre)

1

Retrieval (Arama)

Kullanıcı sorgusunu vektör araması ile ilgili mekanları bulur

• Sentence Transformers ile embedding
• Qdrant'ta semantik arama
• Konum bazlı filtreleme
↓
2

Augmentation (Zenginleştirme)

Bulunan mekanları LLM'e context olarak sağlar

• Mekan bilgilerini formatlama
• Context oluşturma
• Prompt hazırlama
↓
3

Generation (Üretim)

LLM kişiselleştirilmiş öneri metni üretir

• Gemma 2 ile metin üretimi
• Türkçe yanıt formatlama
• Gerekçe analizi

Avantajlar: RAG mimarisi sayesinde sistem, veritabanındaki güncel mekan bilgilerini kullanarak doğru ve bağlamsal öneriler üretebilir.

🔧 Backend API Özellikleri (Utku)

API Endpoint'leri

🔐

Authentication

POST /auth/register - Kullanıcı kaydı

POST /auth/login - Kullanıcı girişi (JWT)

• Password hashing (bcrypt)
• JWT token yönetimi
• Session management
📍

Mekan İşlemleri

POST /places/ - Yeni mekan ekle

GET /places/ - Mekan listesi

• CRUD işlemleri
• Kategori ve filtreleme
• Konum bazlı sorgulama
💬

Yorum İşlemleri

POST /reviews/ - Yorum ekle

GET /places/{id}/reviews - Mekan yorumları

• QR kod doğrulama
• Rating hesaplama
• Review verification

Utku'nun Katkıları

  • FastAPI tabanlı REST API geliştirdi
  • SQLAlchemy ORM ile veritabanı modelleri oluşturdu
  • JWT authentication sistemi tasarladı
  • CRUD işlemlerini implemente etti
  • Frontend ile API entegrasyonunu sağladı
