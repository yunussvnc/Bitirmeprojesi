🏗 Sistem Mimarisi
Kullandığımız
mimariler
Ölçeklenebilir, modüler ve bulut-native bir yapı tercih ettik.
📱

Mobil (React Native)

Expo & React Native ile çapraz platform. Expo Router ile dosya tabanlı navigasyon, Zustand ile durum yönetimi.

⚙️

Backend (FastAPI)

Python FastAPI; async I/O, JWT kimlik doğrulama, RESTful API tasarımı ve WebSocket desteği.

🤖

AI Katmanı

LLM destekli öneri motoru; mekan vektörizasyonu, kullanıcı profili eşleştirme ve skor hesaplama.

☁️

Bulut (Render / AWS)

Backend Render.com'da konteynerize. Medya dosyaları AWS S3'te, PostgreSQL yönetilen bulut veritabanında.

🔄

Gerçek Zamanlı

WebSocket ile anlık mesajlaşma ve bildirim. Polling fallback mekanizması güvenlik ağı olarak çalışır.

🔐

Güvenlik

JWT access + refresh token, bcrypt şifre hashleme, rate limiting ve kullanıcı engelleme / raporlama sistemi.

⚙️ Backend
Sunucu tarafı
nasıl çalışıyor?
FastAPI ile yüksek performanslı, async ve modüler bir REST API mimarisi kuruldu.
FastAPI Python 3.12 SQLAlchemy PostgreSQL WebSocket JWT Auth
🔀
Modüler Router Yapısı auth, users, places, feed, stories, messages, notifications, recommend, saved, community — her domain ayrı router.
⚡
Async I/O Tüm veritabanı ve ağ işlemleri async/await ile yazıldı. Eş zamanlı istek kapasitesi geleneksel Flask'a göre ~5x daha yüksek.
🔐
Güvenlik Katmanı JWT access (15dk) + refresh (30gün) token döngüsü, bcrypt hash, rate limiting, engelleme ve raporlama sistemi.
📡
Gerçek Zamanlı WebSocket Mesajlaşma için WebSocket endpoint; 30 saniyelik polling fallback ile garantili mesaj teslimi.
📤
Medya Yükleme Pipeline Aşamalı yükleme: validasyon → sıkıştırma → AWS S3 upload → post oluşturma.
