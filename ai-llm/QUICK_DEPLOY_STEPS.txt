🔗 SERVİSLER ARASI İLETİŞİM:

   Backend → AI Service çağrıları:
   
   1. Kullanıcı backend'e istek atar
   2. Backend, AI servisi gerekiyorsa AI_SERVICE_URL'i kullanır
   3. AI servisi yanıt döner
   4. Backend mobil app'e yanıt gönderir
   
   Örnek backend kodu:
   
   import httpx
   
   AI_SERVICE_URL = os.getenv("AI_SERVICE_URL", "http://localhost:8080")
   
   async def get_smart_recommendations(query: str):
       async with httpx.AsyncClient() as client:
           response = await client.post(
               f"{AI_SERVICE_URL}/api/smart-search-v2",
               json={"query": query, "location": "Istanbul"}
           )
           return response.json()
